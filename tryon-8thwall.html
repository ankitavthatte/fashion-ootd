SETUP NEEDED

🧥 3D Try-On — 8th Wall

This is a starter scaffold. To make it live:

  1. Create a project at 8thwall.com and copy its App Key.
  2. Add this page's domain to the project's authorized domains.
  3. Drop a 3D jacket jacket.glb next to this file (or set a URL).
  4. Edit window.OOTD_CONFIG at the top of this file with your App Key + model path.

Then reload on your phone. See the README (“3D try-on on 8th Wall”) for the full walkthrough.
